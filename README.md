## About

Information Technology Engineering student at **UIDE** (5th semester), focused on building secure software. I design interfaces with **React** and **TypeScript**, backends with **Node.js** and **NestJS**, and deploy them on the cloud. Then I try to break them, because understanding how a system gets attacked is the best way to protect it.

- Building [CodeVote](https://codevote.lat), a secure and auditable student voting platform
- Practicing ethical hacking and risk assessment (OWASP Juice Shop, NIST SP 800-30)
- Deploying on AWS, Azure and GCP with Docker, Nginx, Terraform and CI/CD
- Leveling up in backend architecture and offensive security
